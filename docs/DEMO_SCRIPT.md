# Thaw 3-Minute Panel Presentation Demo Script

## 1. The Hook (0:00 - 0:45)
- **Visual:** Open landing page (`/`).
- **Narrative:** "Conventional productivity apps assume everyone has neurotypical consistency. For students experiencing executive dysfunction, rigid alarms and red 'overdue' labels create panic. Meet **Thaw**, a gentle co-op for getting unstuck."

## 2. Spoon Check-in & Dashboard (0:45 - 1:30)
- **Visual:** Click "Open App" to view Dashboard (`/dashboard`).
- **Narrative:** "When students arrive overwhelmed, Thaw does not ask for peak performance. We start with a Spoon Energy Check-in. Let's select '2/5 Spoons' (Low Energy)."
- **Highlight:** Notice how recommendations instantly shift to low-friction maintenance tasks.

## 3. AI Task Sequencer & RAG (1:30 - 2:15)
- **Visual:** Navigate to AI Sequencer (`/sequencer`).
- **Narrative:** "Let's input a daunting task: *'I need to finish my entire research report by tomorrow.'*"
- **Highlight:** Thaw returns a compassionate acknowledgment, a 2-minute starting step, and 5 small steps grounded in RAG cognitive strategies. Click to view the RAG Strategy sources.

## 4. Focus Timer & Rest Mode (2:15 - 3:00)
- **Visual:** Start the 2-minute focus timer (`/timer`), then visit Rest Sanctuary (`/rest`).
- **Narrative:** "With a body-double companion, the student can start a 2-minute timer. If energy depletes further, they can step into Guilt-Free Rest Mode for guided breathing. Thaw proves that taking care of your mind is true progress."
